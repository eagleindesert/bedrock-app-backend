# Auth API (`/api/auth`)

세션 기반 인증. 로그인 성공 시 `SESSION` 쿠키가 발급되며, 이후 인증이 필요한 요청은 이 쿠키를 함께 전송해야 합니다.  
CSRF는 비활성화되어 있어 별도의 토큰이 필요하지 않습니다.

---

## 1. 회원가입 — `POST /api/auth/signup`

- **인증**: 불필요 (`permitAll`)
- **응답**: `200 OK` (본문 없음)
- **예외**: 이미 가입된 이메일인 경우 `IllegalArgumentException("이미 사용 중인 이메일입니다.")` 발생

### Request Body
| 필드명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `email` | String | Y | 사용자 이메일 | `test@example.com` |
| `password` | String | Y | 비밀번호 | `password1234` |
| `nickname` | String | Y | 닉네임 | `테스터` |

---

## 2. 로그인 — `POST /api/auth/login`

- **인증**: 불필요 (`permitAll`)
- **응답**:
  - 성공: `200 OK` + `Set-Cookie: SESSION=...`
  - 실패: `401 Unauthorized` (`BadCredentialsException`)

### Request Body
| 필드명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `email` | String | Y | 사용자 이메일 | `test@example.com` |
| `password` | String | Y | 비밀번호 | `password1234` |

---

## 3. 내 정보 조회 — `GET /api/auth/me`

- **인증**: 필요 (세션 쿠키)
- **응답**:
  - 성공: `200 OK` + 사용자 정보 (JSON)
  - 실패: `401 Unauthorized`

---

## 4. 로그아웃 — `POST /api/auth/logout`

- **인증**: 필요 (세션 쿠키)
- **Request Body**: 없음
- **응답**: `200 OK` (세션 무효화)

---

## 5. 회원 탈퇴 — `DELETE /api/auth/withdraw`

- **인증**: 필요 (세션 쿠키)
- **Request Body**: 없음
- **응답**: `200 OK` (Soft Delete + 세션 무효화)

# Item API (`/api/v1/items`)

모든 엔드포인트는 **인증 필요**(세션 쿠키). `owner_id`는 요청 본문이 아니라 **로그인 세션에서 자동 지정**됩니다.

- `id`: UUID 형식
- `attributes`: 임의의 JSON 객체 (JSONB)
- 인증 없이 호출 시 `401 Unauthorized`, 존재하지 않거나 타인 소유 리소스 접근 시 `404 Not Found`

---

## 1. 생성 — `POST /api/v1/items`

- **응답**: `201 Created` + 생성된 아이템 객체

### Request Body
| 필드명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `name` | String | Y | 아이템 이름 | `노트북` |
| `attributes` | Object (JSONB) | N | 임의의 속성 객체 | `{"brand": "Dell", "ram": 32, "tags": ["work", "portable"]}` |

### Response Body
| 필드명 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `id` | String (UUID) | 아이템 고유 식별자 | `3f9a1c2e-7b4d-4e8a-9c1f-0a2b3c4d5e6f` |
| `name` | String | 아이템 이름 | `노트북` |
| `ownerId` | Long | 소유자 사용자 ID | `1` |
| `attributes` | Object (JSONB) | 사용자 정의 속성 객체 | `{"brand": "Dell", "ram": 32, "tags": ["work", "portable"]}` |
| `createdAt` | String (ISO-8601) | 생성 일시 | `2026-06-24T01:55:00` |
| `updatedAt` | String (ISO-8601) | 수정 일시 | `2026-06-24T01:55:00` |

---

## 2. 목록 조회 — `GET /api/v1/items`

- 내 소유 아이템 목록을 반환합니다.
- **응답**: `200 OK` + 아이템 객체 배열

---

## 3. 단건 조회 — `GET /api/v1/items/{id}`

- **응답**:
  - 성공: `200 OK` + 아이템 객체
  - 실패: `404 Not Found` (미존재 또는 타인 소유 리소스)

---

## 4. 수정 — `PUT /api/v1/items/{id}`

- 전체 교체 방식입니다 (`name`, `attributes` 모두 전달).
- **응답**: `200 OK` + 수정된 아이템 객체

### Request Body
| 필드명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `name` | String | Y | 수정할 아이템 이름 | `노트북 (업무용)` |
| `attributes` | Object (JSONB) | N | 수정할 속성 객체 | `{"brand": "Dell", "ram": 64, "tags": ["work"]}` |

---

## 5. 삭제 — `DELETE /api/v1/items/{id}`

- Soft Delete (`deleted_at` 설정). 삭제 후 조회 시 `404 Not Found` 응답.
- **응답**: `204 No Content`

# Collection API (`/api/v1/collections`)

모든 엔드포인트는 **인증 필요**(세션 쿠키).  
컬렉션 생성 시 요청한 사용자가 `collection_users`에 `role=owner`로 자동 등록되며, 목록 조회는 **내가 속한 컬렉션만** 반환합니다.

- `id`: UUID 형식
- `kind`: `calendar` / `notebook` / `semester` 중 하나 (대소문자 구분 없이 입력 가능, 응답은 소문자)
- `attributes`: 임의의 JSON 객체 (JSONB)
- 인증 없이 호출 시 `401 Unauthorized`, 존재하지 않는 kind 값 입력 시 `400 Bad Request`

---

## 1. 생성 — `POST /api/v1/collections`

- **응답**: `201 Created` + 생성된 컬렉션 객체 (`role=owner` 자동 지정)

### Request Body
| 필드명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `kind` | String | Y | 컬렉션 종류 (`calendar`, `notebook`, `semester`) | `calendar` |
| `name` | String | Y | 컬렉션 이름 | `2026-2학기 시간표` |
| `color` | String | N | 컬렉션 테마 색상 | `#FF6B6B` |
| `icon` | String | N | 컬렉션 아이콘 식별자 | `calendar-icon` |
| `attributes` | Object (JSONB) | N | 임의의 속성 객체 | `{"semester": "2026-2"}` |

### Response Body
| 필드명 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `id` | String (UUID) | 컬렉션 고유 식별자 | `3f9a1c2e-7b4d-4e8a-9c1f-0a2b3c4d5e6f` |
| `kind` | String | 컬렉션 종류 | `calendar` |
| `name` | String | 컬렉션 이름 | `2026-2학기 시간표` |
| `color` | String | 컬렉션 색상 | `#FF6B6B` |
| `icon` | String | 컬렉션 아이콘 | `calendar-icon` |
| `attributes` | Object (JSONB) | 사용자 정의 속성 객체 | `{"semester": "2026-2"}` |
| `role` | String | 현재 사용자의 역할 | `owner` |
| `createdAt` | String (ISO-8601) | 생성 일시 | `2026-07-10T01:55:00` |
| `updatedAt` | String (ISO-8601) | 수정 일시 | `2026-07-10T01:55:00` |

---

## 2. 목록 조회 — `GET /api/v1/collections`

- 내가 속한 컬렉션 목록을 반환합니다 (owner 및 초대된 editor/viewer 포함).
- **응답**: `200 OK` + 컬렉션 객체 배열

### Query Parameters
| 파라미터명 | 타입 | 필수 여부 | 설명 | 예시 |
|---|---|:---:|---|---|
| `kind` | String | N | 컬렉션 종류 필터링 (생략 시 전체) | `calendar` |
| `owner` | String | N | 내 컬렉션만 조회 명시 파라미터 | `me` |
