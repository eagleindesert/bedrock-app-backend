# 복합 프리셋 사용자 시나리오

> 
> 
> 
> > 5계층 어휘(트리거·액션·블럭·뷰·아이템)를 사용한 복합 프리셋 시나리오.
> 각 시나리오는 2개 이상의 블럭이 연결된 파이프라인 패턴을 대표한다.
> **복합 패턴의 핵심:** 블럭이 누적한 서로 다른 모듈의 필드가 하나의 아이템에 합쳐지며,
> 결과 아이템은 보유 필드에 따라 여러 뷰에 자연 등장한다 (ADR-19 다중 필드 보유).
> > 
> 
> ---
> 
> ## SC-1 — 아이디어 캐치
> 
> **이다은 (21세, 대학생)**
> 버스 이동 중 서포터즈 콘텐츠 아이디어가 떠올랐다. 날짜만 따로 잡거나 메모만 따로 남기면 나중에 연결이 안 된다는 걸 안다. 발표 예정일과 아이디어 내용을 한 아이템으로 남기고 싶다.
> 
> **패턴:** 복합 블럭 — 캘린더 + 메모 → 단일 아이템
> 
> **트리거:** 캘린더 뷰 `fab_click` → `{}`
> 
> ```mermaid
> flowchart LR
>   T1["캘린더 뷰<br/>fab_click"]:::trigger --> B1["캘린더 블럭<br/>날짜·시각 입력"]:::block --> B2["메모 블럭<br/>아이디어 내용 입력"]:::block --> V1["캘린더 뷰<br/>생성 아이템 표시"]:::view
>   classDef trigger fill:#EEEDFE,stroke:#534AB7,color:#26215C
>   classDef block fill:#E1F5EE,stroke:#0F6E56,color:#04342C
>   classDef view fill:#FAEEDA,stroke:#854F0B,color:#412402
> ```
> 
> 1. 캘린더 뷰 FAB(`+ 새 일정`) 탭 → `fab_click` 발동, 빈 컨텍스트로 액션 시작
> 2. **캘린더 블럭 활성화** → 날짜·시각 직접 입력 (예: 이번 주 토요일 14:00–15:00, 이름: "서포터즈 릴스 기획") → 컨텍스트에 `name`, `start_at`, `end_at` 누적
> 3. **메모 블럭 활성화** → 아이디어 내용 입력 (예: "팝업스토어 릴스 — 입장 전/중/후 3컷 구성, 브랜드 BGM 검토 필요") → 컨텍스트에 `content` 추가 누적
> 4. **종료 뷰: 캘린더 뷰** → 결과 아이템이 해당 날짜 슬롯에 표시
> 
> **결과 아이템 attributes:**
> 
> ```
> { name, start_at, end_at, content }
> ```
> 
> - 캘린더 뷰: `start_at`·`end_at` 보유 → 해당 날짜 슬롯에 블럭으로 표시
> - 메모 뷰: `content` 보유 → 동일 아이템이 메모 리스트에도 자연 등장
> 
> ---
> 
> ## SC-2 — 팀 프로젝트
> 
> **이다은 (21세, 대학생)**
> 팀 회의가 끝났다. 역할 분담은 결정됐는데 단톡에 올리면 세 시간 뒤 또 "이거 누가 하기로 했지?"가 나올 게 뻔하다. 할 일 등록과 동시에 회의 맥락도 같은 아이템 안에 남겨두고 싶다.
> 
> **패턴:** 복합 블럭 — 투두 + 메모 → 단일 아이템
> 
> **트리거:** 투두 뷰 `fab_click` → `{}`
> 
> ```mermaid
> flowchart LR
>   T2["투두 뷰<br/>fab_click"]:::trigger --> B3["투두 블럭<br/>할 일·마감·우선순위 입력"]:::block --> B4["메모 블럭<br/>회의 맥락·배경 입력"]:::block --> V2["투두 뷰<br/>생성 아이템 표시"]:::view
>   classDef trigger fill:#EEEDFE,stroke:#534AB7,color:#26215C
>   classDef block fill:#E1F5EE,stroke:#0F6E56,color:#04342C
>   classDef view fill:#FAEEDA,stroke:#854F0B,color:#412402
> ```
> 
> 1. 투두 뷰 FAB(`+ 새 투두`) 탭 → `fab_click` 발동, `status` 기본값 `open`으로 컨텍스트 시작
> 2. **투두 블럭 활성화** → 할 일 이름·마감일·우선순위 입력 (예: "발표 자료 초안 작성 / 5월 28일 / 우선순위 1") → 컨텍스트에 `name`, `status=open`, `due_at`, `priority` 누적
> 3. **메모 블럭 활성화** → 회의에서 나온 배경 맥락 입력 (예: "3분 발표 + 5분 QA 형식, 팀장이 데모 담당 확정, 자료 양식은 학과 포맷 사용") → 컨텍스트에 `content` 추가 누적
> 4. **종료 뷰: 투두 뷰** → 결과 아이템이 리스트에 표시
> 
> **결과 아이템 attributes:**
> 
> ```
> { name, status, due_at, priority, content }
> ```
> 
> - 투두 뷰: `status` 보유 → 체크박스 행으로 표시
> - 메모 뷰: `content` 보유 → 동일 아이템이 메모 리스트에도 자연 등장
>

> ## SC-3 — 날짜별 강의 노트
> 
> **이다은 (21세, 대학생)**
> 시간표에 등록된 강의를 누르면 그 강의의 특정 날짜 수업 노트를 바로 만들고 싶다. 날짜와 강의명이 함께 붙은 메모가 자동으로 생기면 나중에 찾기도 편하다.
> 
> **패턴:** 복합 블럭 — 시간표 + 캘린더 + 메모 → 단일 아이템
> 
> **트리거:** 시간표 뷰 `item_click` → `{ item_id }`
> 
> ```mermaid
> flowchart LR
>   T3["시간표 뷰<br/>item_click"]:::trigger --> B5["시간표 블럭<br/>강의 정보 확인"]:::block --> B6["캘린더 블럭<br/>날짜 선택"]:::block --> B7["메모 블럭<br/>수업 노트 입력"]:::block --> V3["시간표 뷰<br/>강의 그리드 표시"]:::view
>   classDef trigger fill:#EEEDFE,stroke:#534AB7,color:#26215C
>   classDef block fill:#E1F5EE,stroke:#0F6E56,color:#04342C
>   classDef view fill:#FAEEDA,stroke:#854F0B,color:#412402
> ```
> 
> 1. 시간표 그리드에서 기존 강의 블럭 탭 → `item_click` 발동, `{ item_id }` 컨텍스트 시드
> 2. **시간표 블럭 활성화** → 기존 강의 정보 로드 (예: "데이터구조 / 화 / 10:00–12:00"), 학기 디폴트 → 컨텍스트에 `name`, `day_of_week`, `start_time` 누적
> 3. **캘린더 블럭 활성화** → 이번 수업 날짜 선택 (예: 2026-05-26) → 컨텍스트에 `start_at`, `end_at` 누적
> 4. **메모 블럭 활성화** → `name` 자동 설정 ("데이터구조 20260526"), 수업 노트 입력 → 컨텍스트에 `content` 누적
> 5. **종료 뷰: 시간표 뷰** → 원래 강의 그리드로 복귀
> 
> **결과 아이템 attributes:**
> 
> ```
> { name(강의명+날짜 자동), start_at, end_at, content }
> ```
> 
> - 메모 뷰: `content` 보유 → "데이터구조 20260526"으로 표시
> - 캘린더 뷰: `start_at`·`end_at` 보유 → 해당 날짜에 자연 등장
>

> ## SC-4 — 시험 D-30 모드
> 
> **최준혁 (25세, 휴학생)**
> 복학을 앞두고 중간고사가 한 달 앞으로 다가왔다. 시험 날짜를 달력에 박는 김에, 이 시험을 위해 지금 당장 시작해야 할 일 목록도 같이 만들고 싶다. 앱 두 개를 왔다 갔다 하기 싫다.
> 
> **패턴:** 복합 블럭 — 캘린더 + 투두 → 단일 아이템
> 
> **트리거:** 캘린더 뷰 `day_click` → `{ date }` (월간 모드)
> 
> ```mermaid
> flowchart LR
>   T4["캘린더 뷰<br/>day_click"]:::trigger --> B8["캘린더 블럭<br/>시험일 종일 입력"]:::block --> B9["투두 블럭<br/>준비 할 일·마감 입력"]:::block --> V4["캘린더 뷰<br/>생성 아이템 표시"]:::view
>   classDef trigger fill:#EEEDFE,stroke:#534AB7,color:#26215C
>   classDef block fill:#E1F5EE,stroke:#0F6E56,color:#04342C
>   classDef view fill:#FAEEDA,stroke:#854F0B,color:#412402
> ```
> 
> 1. 캘린더 뷰(월간 모드)에서 시험 날짜 탭 → `day_click` 발동, `{ date }` 컨텍스트 시드
> 2. **캘린더 블럭 활성화** → `date` prefill된 상태, 종일 이벤트 디폴트로 열림 → 시험명 입력 (예: "자료구조 중간고사"), 시간 범위는 종일 유지 → 컨텍스트에 `name`, `start_at`, `end_at`(종일) 누적
> 3. **투두 블럭 활성화** → 시험 준비 할 일과 마감일 입력 (예: "3·4단원 복습 / 5월 30일", "기출 3회분 풀기 / 6월 3일") → 컨텍스트에 `status=open`, `due_at` 추가 누적
> 4. **종료 뷰: 캘린더 뷰** → 결과 아이템이 시험 당일 종일 슬롯에 표시
> 
> **결과 아이템 attributes:**
> 
> ```
> { name, start_at, end_at, status, due_at }
> ```
> 
> - 캘린더 뷰: `start_at`·`end_at` 보유 → 시험 당일 종일 블럭으로 표시
> - 투두 뷰: `status` 보유 → 준비 할 일 행으로도 자연 등장 (투두 자동 등장 패턴)
>

> ## 복합 프리셋 요약
> 
> | # | 프리셋명 | 트리거 | 블럭 체인 | 종료 뷰 | 결과 아이템 |
> | --- | --- | --- | --- | --- | --- |
> | SC-1 | 아이디어 캐치 | 캘린더 `fab_click` | 캘린더 → 메모 | 캘린더 뷰 | `start_at`+`end_at`+`content` |
> | SC-2 | 팀 프로젝트 | 투두 `fab_click` | 투두 → 메모 | 투두 뷰 | `status`+`due_at`+`content` |
> | SC-3 | 날짜별 강의 노트 | 시간표 `item_click` | 시간표 → 캘린더 → 메모 | 시간표 뷰 | `name`(강의명+날짜)+`start_at`+`end_at`+`content` |
> | SC-4 | 시험 D-30 모드 | 캘린더 `day_click` | 캘린더 → 투두 | 캘린더 뷰 | `start_at`+`end_at`+`status`+`due_at` |
> 
> > 4개 시나리오 모두 ADR-19 다중 필드 보유로 단일 아이템 결과. SC-3은 강의(시간표)를 시드로 캘린더 날짜를 받아 메모 제목을 "강의명+날짜"로 자동 생성하는 흐름.
